はじめかた

NEON GEOMETRY

幾何学の敵を自動攻撃で倒しながら、3 分間生き残るゲームです。
遊び方は、ゲーム内のタイトル画面と「ライブラリ」に書いてあります。

はじめかた

動作環境：Windows 10 / 11（64 ビット版）。
インストールは不要で、別のソフトを入れる必要もありません。
Macintosh やスマートフォンには対応していません。

  1. ダウンロードする
    配布ページで zip ファイルをダウンロードします。
    ブラウザや Google Drive が「ウイルス スキャンを実行できません」などの確認を表示した場合は、内容を確認のうえダウンロードを続けてください。
  2. 展開する
    ダウンロードした zip ファイルを右クリックし、「すべて展開」を選びます。
    zip のまま中のファイルを開くと、正しく動きません。
    展開する前に、zip ファイルを右クリック →「プロパティ」→「許可する」にチェック →「OK」とすると、次の手順の警告が出なくなる場合があります。
  3. 起動する
    展開したフォルダの NEON GEOMETRY.exe をダブルクリックします。
    タイトル画面が開きます。
    初めて起動するとき、次のような警告が出ることがあります。
    「詳細情報」を押し、表示された「実行」を押してください。
    ① 最初の画面
    Windows によって PC が保護されました
    Microsoft Defender SmartScreen は認識されないアプリの起動を停止しました。このアプリを実行すると、PC に問題が起こる可能性があります。

    詳細情報
    実行しない
    ② 「詳細情報」を押した後
    Windows によって PC が保護されました
    Microsoft Defender SmartScreen は認識されないアプリの起動を停止しました。このアプリを実行すると、PC に問題が起こる可能性があります。
    アプリ: NEON GEOMETRY.exe
    発行元: 不明な発行元
    実行実行しない

    画面は一例です。
    Windows のバージョンによって表示が異なります。
    この警告は、発行元を証明する電子署名を付けていないアプリで表示されます。

  4. 遊ぶ
    タイトル画面の「スタート」を押すか、Enter / Space で始めます。
    操作の要点は画面下に表示されます。
    武器や強化の説明は「ライブラリ」で確認できます。
  5. 終了する
    タイトル画面の「終了」を押すか、ウィンドウを閉じます。

削除するとき

ゲームを終了してから、展開したフォルダごと削除してください。
ハイスコアなどのセーブデータは、展開したフォルダの外に残ります。
場所は %APPDATA%\NEON GEOMETRY（エクスプローラーのアドレス欄に貼り付けて開けます）です。
不要なら、このフォルダも削除してください。
レジストリは使いません。

うまく動かないとき

  • 起動できない：上記の SmartScreen の手順を試してください。
    それでもだめなときは、zip をいったん削除してから、配布ページから取り直して展開し直してください。
  • 画面が暗い・動作が重い：ほかの重いアプリを閉じ、グラフィックドライバーを最新にしてみてください。
